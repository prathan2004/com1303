# เอกสารประกอบสัปดาห์ที่ 15

[กลับหน้าสัปดาห์](../README.md) · [กลับสารบัญรายวิชา](../../README.md#สารบัญ)

โฟลเดอร์นี้เตรียมไว้สำหรับสไลด์ ใบงาน เอกสารอ่านเพิ่มเติม และโค้ดตัวอย่างประจำสัปดาห์ ขณะนี้ยังไม่มีไฟล์ประกอบเพิ่มเติม

เมื่อมีเอกสาร ให้เลือกไฟล์เพื่ออ่านบน GitHub หรือเปิดไฟล์แล้วเลือกปุ่มดาวน์โหลดหรือ Download raw file เพื่อบันทึกลงเครื่อง

สำหรับผู้สอน: เพิ่มไฟล์ลงในโฟลเดอร์นี้ แล้วเพิ่มลิงก์ชื่อไฟล์ใน README ของสัปดาห์เพื่อให้นักศึกษาเข้าถึงได้สะดวก
