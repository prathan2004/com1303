# COM 1303 การพัฒนาเว็บขั้นพื้นฐาน

แหล่งเรียนรู้ประกอบรายวิชา **COM 1303 การพัฒนาเว็บขั้นพื้นฐาน** มหาวิทยาลัยราชภัฏเชียงใหม่ สำหรับฝึกออกแบบ พัฒนา ทดสอบ และเผยแพร่เว็บไซต์ ตั้งแต่การวางโครงสร้างเนื้อหาไปจนถึงการนำเสนอผลงานเว็บไซต์ที่ใช้งานได้จริง

> ข้อมูลรายวิชา แผนการสอน และเกณฑ์ประเมินในหน้านี้เรียบเรียงจากแผนบริหารการจัดการเรียนรู้รายวิชา (OBE3) ภาคการศึกษาที่ 2 ปีการศึกษา 2569 ฉบับปรับปรุงวันที่ 20 ตุลาคม 2569 ส่วนแนวทางฝึกปฏิบัติบน GitHub เป็นคำแนะนำประกอบการเรียน

## คำอธิบายรายวิชา

องค์ความรู้ทางด้านเทคโนโลยีเกี่ยวกับการพัฒนาเว็บ ความรู้เบื้องต้นเกี่ยวกับการออกแบบและจัดการเว็บไซต์ด้วยภาษาเอชทีเอ็มแอล การจัดการหน้าเว็บเพจด้วยแคสเคดดิงสไตล์ชีตส์ เฟรมเวิร์กเพื่อการจัดหน้าเว็บเพจเพื่อแสดงผลกับอุปกรณ์ที่หลากหลาย ภาษาสคริปต์ การใช้เครื่องมือช่วยสร้างเว็บ ฝึกปฏิบัติการพัฒนาเว็บไซต์เบื้องต้น และการนำเว็บไซต์เข้าสู่เครื่องแม่ข่ายเพื่อเผยแพร่บนอินเทอร์เน็ต

**สมรรถนะสำคัญ:** ออกแบบ พัฒนา ทดสอบ และเผยแพร่เว็บไซต์เบื้องต้นได้

รายวิชามุ่งให้ผู้เรียนเข้าใจการทำงานของเว็บไซต์ ออกแบบโครงสร้างและหน้าตาให้เหมาะกับผู้ใช้ พัฒนาเว็บด้วย HTML, CSS, JavaScript และเครื่องมือช่วยพัฒนา รวมทั้งเผยแพร่ผลงานโดยตระหนักถึงจริยธรรมในการใช้ทรัพยากรดิจิทัล

## รูปแบบการเรียนรู้

เรียนรู้ผ่านการลงมือทำ โดยผสมผสานการบรรยายสั้น การสาธิต การฝึกในห้องปฏิบัติการ การเรียนรู้โดยใช้ปัญหาเป็นฐาน การทำงานคู่และกลุ่มย่อย การวิจารณ์ผลงานเพื่อน และการนำเสนอผลงานจริง

ผู้เรียนจะค่อย ๆ พัฒนางานตั้งแต่การวิเคราะห์ผู้ใช้ วางโครงร่าง เขียนโค้ด ทดสอบ แก้ปัญหา และสะท้อนสิ่งที่เรียนรู้จากการปรับปรุงเว็บไซต์

## เริ่มต้นฝึกพัฒนาเว็บไซต์

แนวทางต่อไปนี้เป็นคำแนะนำสำหรับฝึกด้วยตนเอง สามารถปรับตามเครื่องมือและโจทย์ที่ผู้สอนกำหนด

1. เตรียมโปรแกรมแก้ไขโค้ดและเว็บเบราว์เซอร์ที่มี Developer Tools
2. สร้างโฟลเดอร์สำหรับงาน และสร้างไฟล์ `index.html`
3. ทดลองเขียนโครงสร้าง HTML ต่อไปนี้ แล้วบันทึกด้วยการเข้ารหัส UTF-8
4. เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ และทดลองเปลี่ยนข้อความ
5. เมื่อเรียน CSS และ JavaScript ให้แยกไฟล์จัดรูปแบบและสคริปต์ แล้วทดสอบการเชื่อมโยงไฟล์

```html
<!doctype html>
<html lang="th">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>เว็บไซต์แรกของฉัน | COM 1303</title>
  </head>
  <body>
    <header>
      <h1>เว็บไซต์แรกของฉัน</h1>
    </header>
    <main>
      <p>เริ่มต้นเรียนรู้การพัฒนาเว็บขั้นพื้นฐาน</p>
    </main>
    <footer>
      <p>ผลงานประกอบรายวิชา COM 1303</p>
    </footer>
  </body>
</html>
```

## แนวทางจัดเก็บงานบน GitHub

ให้นักศึกษาจัดเก็บงานในคลัง GitHub ของตนเอง โดยสร้างโฟลเดอร์ชื่อ **`week` ตามด้วยหมายเลขสัปดาห์ของงาน** เช่น `week2`, `week4` และ `week10` แล้วนำไฟล์ทั้งหมดของงานสัปดาห์นั้นใส่ไว้ภายในโฟลเดอร์ พร้อมเขียนไฟล์ **`README.md` ประจำสัปดาห์** เพื่อให้ผู้อ่านเข้าใจว่างานคืออะไร ทำงานอย่างไร และได้เรียนรู้อะไร

### ขั้นตอนจัดเก็บงาน

1. สร้างโฟลเดอร์ตามสัปดาห์ที่ได้รับมอบหมาย เช่น งานสัปดาห์ที่ 4 ให้ใช้ชื่อ `week4` โดยใช้ตัวพิมพ์เล็กและไม่เว้นวรรค
2. ใส่ไฟล์งาน เอกสาร ภาพ และไฟล์ประกอบทั้งหมดไว้ในโฟลเดอร์ของสัปดาห์นั้น หากมีหลายกิจกรรม สามารถสร้างโฟลเดอร์ย่อยภายในได้
3. สร้างไฟล์ `README.md` ไว้ภายในโฟลเดอร์เดียวกัน แล้วอธิบายงานด้วยภาษาของตนเองตามตัวอย่างด้านล่าง
4. ตรวจว่าไฟล์ที่งานต้องใช้และลิงก์ใน README เปิดได้ครบ แล้วบันทึกการเปลี่ยนแปลงและอัปโหลดขึ้น GitHub
5. ส่งลิงก์โฟลเดอร์ของสัปดาห์นั้นตามช่องทางและกำหนดเวลาที่ผู้สอนแจ้ง

สร้างโฟลเดอร์เฉพาะสัปดาห์ที่มีงานมอบหมาย และใช้หมายเลขสัปดาห์จริง เช่น งานสัปดาห์ที่ 9 ให้ใช้ `week9` แม้สัปดาห์ที่ 8 จะเป็นสัปดาห์สอบ

### สิ่งที่ต้องอธิบายใน README ประจำสัปดาห์

- **ผู้จัดทำและหัวข้องาน:** ชื่อผู้จัดทำ หมายเลขสัปดาห์ และชื่องาน
- **วัตถุประสงค์:** งานนี้ฝึกเรื่องใด และต้องการให้ผลงานทำอะไรได้
- **รายละเอียดผลงาน:** สิ่งที่ทำ องค์ประกอบสำคัญ และเทคโนโลยีหรือเครื่องมือที่ใช้
- **ไฟล์และวิธีเปิดใช้งาน:** ไฟล์หลักอยู่ที่ใด ต้องเปิดหรือทำตามขั้นตอนใดเพื่อดูผลงาน
- **ผลลัพธ์และสิ่งที่ได้เรียนรู้:** สิ่งที่ทำสำเร็จ ปัญหาที่พบ วิธีแก้ไข และสิ่งที่ต้องปรับปรุง
- **แหล่งอ้างอิง:** ที่มาของภาพ เนื้อหา โค้ด หรือเครื่องมือที่นำมาช่วยทำงาน หากเผยแพร่เว็บไซต์แล้วให้เพิ่มลิงก์ผลงานด้วย

### ตัวอย่าง README ของนักศึกษา

คัดลอกตัวอย่างนี้ไปปรับให้ตรงกับงานจริง ตัวอย่างเป็น README สำหรับโฟลเดอร์ `week4`

```markdown
# สัปดาห์ที่ 4 โครงสร้าง HTML และแท็กพื้นฐาน

ชื่อ–นามสกุล: [ชื่อของนักศึกษา]

## วัตถุประสงค์ของงาน

ฝึกสร้างหน้าเว็บแนะนำตัวด้วยโครงสร้าง HTML และใช้แท็กพื้นฐานจัดเนื้อหาให้อ่านเข้าใจง่าย

## รายละเอียดผลงาน

หน้าเว็บประกอบด้วยหัวเรื่อง ข้อความแนะนำตัว รูปภาพ และรายการความสนใจ โดยเขียนด้วย HTML

## ไฟล์ในโฟลเดอร์

- `index.html` — หน้าเว็บหลัก
- `images/profile.png` — ภาพประกอบหน้าเว็บ
- `README.md` — คำอธิบายงาน

## วิธีเปิดดูผลงาน

1. ดาวน์โหลดไฟล์งานพร้อมโฟลเดอร์ images มาไว้ด้วยกัน
2. เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์
3. ตรวจว่าข้อความและภาพแสดงครบถ้วน

## ผลลัพธ์และสิ่งที่ได้เรียนรู้

สามารถสร้างหน้าเว็บที่มีหัวเรื่อง ย่อหน้า รูปภาพ และรายการได้ เข้าใจการกำหนดเส้นทางไฟล์ภาพให้สัมพันธ์กับตำแหน่งของหน้าเว็บ
```

### ตัวอย่างรายการตรวจสอบก่อนส่งผลงาน

- [ ] จัดไฟล์ไว้ในโฟลเดอร์ week ตามด้วยหมายเลขสัปดาห์ เช่น week4

- [ ] เนื้อหาและโครงสร้างหน้าเว็บตรงกับโจทย์และกลุ่มผู้ใช้
- [ ] ลิงก์ รูปภาพ สื่อ และการทำงานของฟอร์มเป็นไปตามที่ออกแบบ

- [ ] บันทึกข้อเสนอแนะและสรุปสิ่งที่ปรับปรุง

## เกณฑ์คุณภาพผลงาน

OBE3 กำหนดการประเมินแบบ Rubric 4 ระดับ ได้แก่ **ดีเยี่ยม ดี พอใช้ และควรปรับปรุง** โดยมีประเด็นพิจารณาดังนี้

| ประเภทงาน | คะแนน | ประเด็นประเมิน |
| --- | ---: | --- |
| ปฏิบัติการออกแบบและพัฒนาเว็บไซต์ | 20 | ความสวยงามและความคิดสร้างสรรค์ การแสดงผลบนอุปกรณ์หลากหลาย ความสัมพันธ์กับหัวข้อ และการใช้เครื่องมือดิจิทัล |
| โครงงานพัฒนาเว็บไซต์และการนำเสนอ | 15 | ความสวยงามและความคิดสร้างสรรค์ การแสดงผลบนอุปกรณ์หลากหลาย ความสัมพันธ์กับหัวข้อ ความสมบูรณ์ของผลงาน และการนำเสนอและการสื่อสาร |
| การประเมินโดยเพื่อนและการสะท้อนผลการเรียนรู้ | 5 | การตอบคำถามและการแสดงความคิดเห็น |

ผลงานในระดับดีเยี่ยมควรมีการออกแบบโดดเด่น สอดคล้องกับหัวข้อ แสดงผลได้สมบูรณ์บนหน้าจอหลากหลาย และใช้เครื่องมือได้เหมาะสม สำหรับโครงงานต้องพร้อมใช้งานและนำเสนอได้ชัดเจน พร้อมตอบคำถามเกี่ยวกับผลงานได้

## ความรับผิดชอบในการพัฒนาเว็บ

รายวิชาให้ความสำคัญกับวินัย จริยธรรมทางวิชาการ ความรับผิดชอบ และความปลอดภัยทางดิจิทัล แนวปฏิบัติประกอบการเรียน ได้แก่ การอ้างอิงผลงานที่นำมาใช้ เคารพสิทธิในภาพและเนื้อหา ตรวจสอบความถูกต้องของโค้ด และหลีกเลี่ยงการเผยแพร่ข้อมูลส่วนบุคคล รหัสผ่าน หรือข้อมูลลับในเว็บไซต์และคลังโค้ดสาธารณะ

หากใช้เครื่องมือปัญญาประดิษฐ์ช่วยพัฒนา ควรตรวจสอบผลลัพธ์ อธิบายโค้ดของตนเองได้ และปฏิบัติตามแนวทางที่ผู้สอนกำหนดสำหรับงานนั้น
