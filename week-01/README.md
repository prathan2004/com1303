# สัปดาห์ที่ 1 แนะนำรายวิชา พื้นฐานเทคโนโลยีเว็บและโครงสร้างเว็บไซต์

[กลับสารบัญรายวิชา](../README.md#สารบัญ)

**เวลาเรียน:** บรรยายและปฏิบัติรวม 4 ชั่วโมง

> หัวข้อและกิจกรรมสรุปจาก OBE3 รายวิชา COM 1303 ภาคการศึกษาที่ 2 ปีการศึกษา 2569

## หัวข้อเรียน

วัตถุประสงค์รายวิชา แผนการเรียน เกณฑ์ประเมิน และพื้นฐานการทำงานของเว็บไซต์

## กิจกรรมการเรียนรู้

สำรวจความรู้เดิมและทำข้อตกลงการเรียนร่วมกัน

## เอกสารและไฟล์ประกอบ

[เปิดโฟลเดอร์เอกสารประจำสัปดาห์](./materials/)

ยังไม่มีสไลด์ ใบงาน หรือไฟล์ตัวอย่างแนบในสัปดาห์นี้ ผู้สอนสามารถเพิ่มเอกสารในโฟลเดอร์ `materials` และเพิ่มลิงก์รายการไฟล์ในหน้านี้ได้

เมื่อต้องการดาวน์โหลด ให้เปิดไฟล์ในโฟลเดอร์เอกสารแล้วเลือกปุ่มดาวน์โหลดหรือ Download raw file บน GitHub หรือดาวน์โหลดทั้งคลังผ่าน Code → Download ZIP จากหน้าหลัก

## การเตรียมตัวและติดตามงาน

อ่านหัวข้อของสัปดาห์และตรวจสอบเอกสารที่ผู้สอนเพิ่มไว้ กำหนดส่งงาน รายละเอียดโจทย์ และประกาศสอบให้ยึดตามที่ผู้สอนแจ้ง
